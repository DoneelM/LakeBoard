Read the measures

Booked value sums non-cancelled bookings, including pending and confirmed stays; it is not settled payments or recognized revenue. Amounts use the sample's dollar convention; no currency conversion is performed. Booking measures use check-in year; guest measures use review-created year. Property counts describe the fixed listing inventory. Unknown ratings stay blank. Sample data never changes.
